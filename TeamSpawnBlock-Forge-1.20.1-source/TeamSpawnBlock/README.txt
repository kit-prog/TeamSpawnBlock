TeamSpawnBlock — исходный проект мода для Minecraft Forge 1.20.1.

Требуется:
- Java JDK 17
- Gradle (или Gradle wrapper из Forge MDK)
- Minecraft Forge 1.20.1, версия 47.x

Сборка:
1. Распакуйте проект.
2. Откройте терминал в папке проекта.
3. Выполните: gradle build
4. Готовый мод появится в build/libs/TeamSpawnBlock-1.0.0.jar
5. Поместите JAR в папку mods клиента/сервера с Forge 1.20.1.

В игре:
 /give @p teamspawn:team_spawn_block

ВАЖНО:
Этот архив — исходный проект, а не готовый .jar для папки mods.
Его нужно собрать. Для сборки можно скопировать gradlew, gradlew.bat и
папку gradle/wrapper из Forge MDK 1.20.1.
